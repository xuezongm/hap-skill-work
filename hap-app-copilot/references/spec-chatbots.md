# AI 智能助手平台规格 (spec-chatbots)

本文档定义 HAP 平台 **AI 智能助手（Chatbot）** 的创建配置、平台限制与提示词设计准则。

---

## 一、 创建配置与核心参数 (`create_chatbot`)

```json
{
  "appId": "应用ID (必填)",
  "name": "助手显示名称 (必填)",
  "welcomeMessage": "场景化欢迎语，明确告知能力边界 (必填)",
  "prompt": "核心系统提示词，注入业务规则与角色定位 (必填)",
  "presetQuestions": [
    "预设业务快捷提问 (必填，最多 5 条，禁止空泛套话)"
  ],
  "sectionId": "挂载的应用导航分组ID (选填)",
  "icon": "图标名称，如 17_6_reddit (选填)",
  "description": "用途简述 (选填)",
  "remark": "内部备注 (选填)"
}
```

---

## 二、 平台核心限制与避坑铁律 (Hard Limits)

1. **预设问题上限 (`presetQuestions`)**：
   - 数组长度必须在 **1~5 项** 之间，超出 5 项 API 直接报错；
   - 必须结合应用业务生成具象提问（如“如何发起加急付款？”），禁止“你好”等无效套话；
2. **提示词不可修改**：
   - `update_chatbot` **不支持更新系统提示词（`prompt`）**；
   - 创建时必须一次性编译到位；若提示词需重大调整，需删除后重建。**重建会生成新的 `chatbot_id`，删除前必须先读取并记录原授权角色，重建后必须在各相关角色的 `chatbotPermissions` 中将新 ID 写回以恢复原有权限**；
3. **零臆想参数**：
   - 严禁传入 `model`、`iconColor`、`knowledgeBases`、`worksheets`（接口无此参数）；
4. **权限同步分配**：
   - 新建助手不会自动对所有角色开放，必须在目标角色的 `chatbotPermissions` 中追加 `{ id: chatbot_id, enable: true }`。

---

## 三、 系统提示词 (`prompt`) 编写准则

必须包含以下四段式结构：
1. **角色定位**：明确助手的业务身份与服务对象；
2. **业务规则与知识**：注入当前系统的审核阶梯、分类标准、计算公式与状态流转逻辑；
3. **交互规范**：要求简体中文、分点排版、关键步骤加粗；
4. **安全底线**：严禁伪造未经证实的数据，未知事项引导联系管理员。
